# 🎮 Mobile Week 02 - หน้าแนะนำตัวสไตล์ร้านขายเกมส์ (Gaming Store Theme)

หน้าแนะนำตัวสำหรับส่งการบ้าน / โครงงาน **Mobile Application (Week 02)** ออกแบบด้วยสไตล์ร้านขายเกมส์สุดล้ำ 

---

## 👤 ข้อมูลผู้จัดทำ (Creator Profile)
- **ชื่อเล่น:** เจ๊ก (Jek) ⚡
- **สาขาวิชา:** คอมพิวเตอร์ธุรกิจ (Business Computer) 💻
- **ร้านโครงงาน:** ร้านขายไอดีเกมส์ (Game ID Store) 🛒

---

## 🎨 แนวทางการออกแบบ (Design & Color Palette)
- **ธีม:** Modern Cyberpunk & Gaming Store
- **โทนสีหลัก:**

---

## 📁 ไฟล์ภายในโปรเจกต์
1. **`index.html`** (ไฟล์หลัก): หน้าแนะนำตัวของ **"เจ๊ก"** นักศึกษาคอมพิวเตอร์ธุรกิจและเจ้าของร้านขายไอดีเกมส์ จัดเต็มด้วยค่าสถานะตัวละคร (HP/MP/EXP), ข้อมูลการศึกษา, ตู้โชว์ไอดีเกมแนะนำ (ROV, Valorant, Genshin, Steam), สกิลคอมพิวเตอร์ธุรกิจ, และฟอร์มส่งข้อความทักทาย
2. **`shop.html`**: หน้าร้านค้าจำลองสำหรับต่อยอดโครงงานร้านขายไอดีเกมส์

---

## 🚀 วิธีเปิดใช้งาน
- ดับเบิลคลิกที่ไฟล์ **`index.html`** เพื่อเปิดดูหน้าเว็บผ่านเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม
